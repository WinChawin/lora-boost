# LoRA-Boost

AI Builders 2026 | Noble-Newts | Chawin Sumitra

---

Generative augmentation for long-tail plant species classification (Pl@ntNet-300K).

Per-species LoRA adapters are trained on FLUX.2-klein (DreamBooth-style) to generate synthetic images for rare plant species, used to augment classifier training and improve recall on species with very few real images.
